Four Use Cases

Each vertical runs as a separate detection module with its own model + logic. All share one unified dashboard.

🏭 Manufacturing Defect Detection

Computer vision on conveyor belt or product line. Detects surface cracks, missing parts, colour anomalies, dimensional defects. Flags defective items before packaging. Model: YOLOv8 + anomaly detection.

🦺 Worker Safety / PPE / Accidents

Detects PPE compliance (helmet, vest, gloves), restricted zone intrusions, falls, fire/smoke. Real-time alerts sent to safety manager. Model: YOLOv8-PPE pretrained.

🍽️ Restaurant Efficiency

Key Design Decisions

🧵 Threading Model

Camera capture runs in a background thread, pushing frames into a queue.Queue(maxsize=2). Inference reads from queue. Never blocks the FastAPI event loop.

📡 WebSocket Strategy

Two sockets: /ws/stats pushes JSON every 1s. /stream is MJPEG for annotated video. This keeps UI snappy without frame-dropping.

🔁 Alert Cooldown

Each alert type has a configurable cooldown (e.g. 10s for PPE violation). Prevents alert spam. Stored with timestamp in SQLite so you can show a timeline of events.

// AI Layer

Model Strategy

Use pretrained YOLOv8 weights for everything. Zero training time. Plug in, run, win.

The Golden Rule

Don't train. Finetune at most. Use pretrained weights everywhere.

YOLOv8 pretrained on COCO already detects: person, car, truck, bicycle, motorcycle, chair, dining table, bottle. That covers 80% of what you need across all 4 verticals. Specialty models (PPE, defects) already exist as open-source pretrained weights on Hugging Face + Roboflow.

API Design

FastAPI backend. Clean REST + WebSocket. Your frontend just connects to these endpoints.

Core Endpoints
REST Routes
POST /api/feed/start { source: "rtsp://...", vertical: "safety" } → starts inference pipeline
POST /api/feed/stop Stops current feed + inference
GET /api/stats Returns current metrics JSON for active vertical
GET /api/alerts Paginated alert history from SQLite
GET /api/events?vertical=safety&limit=50 Event log filtered by vertical + time range
GET /stream MJPEG annotated video stream — drop into <img src="/stream">
POST /api/zones/set { zones: [[x1,y1,x2,y2], ...] } — define restricted zones per vertical
GET /api/verticals List of available verticals + their status
WebSocket Events
WS ws://localhost:8000/ws/stats Pushes stats JSON every 1 second to all connected clients
WS ws://localhost:8000/ws/alerts Pushes alert event instantly when triggered (for live alert banner)

main.py Skeleton
# main.py — FastAPI skeleton
from fastapi import FastAPI, WebSocket
from fastapi.responses import StreamingResponse
from camera_manager import CameraManager
from inference_engine import InferenceEngine

app = FastAPI()
camera = CameraManager()
engine = InferenceEngine()

@app.post("/api/feed/start")
async def start_feed(source: str, vertical: str):
    camera.start(source)
    engine.load_module(vertical)
    return { "status": "started" }

@app.get("/stream")
def video_stream():
    return StreamingResponse(
        engine.generate_frames(),
        media_type="multipart/x-mixed-replace; boundary=frame"
    )

@app.websocket("/ws/stats")
async def stats_ws(ws: WebSocket):
    await ws.accept()
    while True:
        stats = engine.get_stats()
        await ws.send_json(stats)
        await asyncio.sleep(1)
