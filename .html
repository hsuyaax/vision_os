Each vertical runs as a separate detection module with its own model + logic. All share one unified dashboard.

Key Design Decisions

🧵 Threading Model

Camera capture runs in a background thread, pushing frames into a queue.Queue(maxsize=2). Inference reads from queue. Video files auto-loop. Never blocks the FastAPI event loop.

📡 WebSocket Strategy

Two sockets: /ws/stats pushes JSON metrics every 1s. /ws/alerts pushes alerts instantly via async pub/sub. Frontend uses a custom useVisionSync React hook with built-in demo mode fallback.

🔁 Alert Cooldown

Each alert type has a configurable cooldown (e.g. 10s for PPE violation). Deduplication by (type, vertical) key. Stored with timestamp in SQLite so you can show a timeline of events. Async broadcast to all WebSocket subscribers.

🎯 Demo Mode

Frontend includes a built-in demo mode toggle that generates simulated metrics, alerts, events, and chart data — no backend needed. Perfect for presentations and offline demos.

📱 Responsive UI

shadcn/ui components with mobile sheet navigation. Desktop sidebar collapses to hamburger menu. All 5 pages work on mobile and desktop breakpoints.

🔌 Connection Health

Sidebar shows real-time backend connection status with /api/health ping. Settings page has a connection tester button. Graceful fallback to demo mode when offline.

// AI Layer

Model Strategy

Use pretrained YOLOv8 weights for everything. Zero training time. Plug in, run, win.

The Golden Rule

Don't train. Finetune at most. Use pretrained weights everywhere.

YOLOv8 pretrained on COCO already detects: person, car, truck, bicycle, motorcycle, chair, dining table, bottle. That covers 80% of what you need across all 4 verticals. Specialty models (PPE, defects) already exist as open-source pretrained weights on Hugging Face + Roboflow.

line = sv.LineZone(
  start=sv.Point(0, 320),
  end=sv.Point(640, 320)
)

# In frame loop:
tracks = tracker.update(detections)
line.trigger(detections=tracks)
count = line.in_count + line.out_count
